Leafy Bee Studio

The private publishing tool behind the Leafy Bee channels.

Leafy Bee Studio is a small, private application that Gabriel and Bella use to publish their own finished videos and short clips to their own Leafy Bee accounts:

  • YouTube: Leafy_Bee (@L34fy_B33)
  • Instagram: @leafy_bee_inc
  • Facebook: the Leafy Bee Inc Page

What it does

It uploads videos the channel owners made, sets their titles, descriptions, captions and thumbnails, schedules or publishes them, and checks that each post went live. It runs on the owners' own computer and acts only on the owners' own accounts.

Who can use it

Only the channel owners. It is not offered to the public, and it never signs in to, reads or posts to anyone else's account.

Privacy policy

Leafy Bee Studio uses YouTube API Services, the Instagram API and the Facebook Pages API. Contact: l34fy.b33@gmail.com
